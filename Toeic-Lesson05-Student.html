Lesson 05 · 關係子句 & 名詞子句

不要背十個字，要理解一個系統 🧠

who / whom / whose / which / that / where / when / why / what / whether——這些字的選擇，靠的是分析句子結構，不是靠感覺。

★三個你必須先懂的基礎概念

① 什麼是子句（Clause）

子句 = 一組有主詞 + 動詞的文字。可以獨立成句（主句），也可以嵌進另一個句子裡補充說明（從句）。

The employee is absent. → 主句
who submitted the report → 從句（子句）

② 什麼是關係代名詞

關係代名詞有兩個功能同時發生：
① 代替前面的名詞（代名詞）
② 連接兩個句子（連接詞）

把它想成橋梁字——一手指著前面的名詞，一手引出後面的描述。

③ 什麼是先行詞（Antecedent）

先行詞 = 關係子句所修飾的名詞，出現在關係代名詞的前面。

先行詞的類型決定選哪個關係詞：
人 → who / whom / whose
事物 → which / that
地點 → where
時間 → when

兩句合一的完整過程
句①
The employee is absent today.
句②
The employee submitted the report. → the employee 出現兩次，第二次用關係代名詞代替
合併
The employee who submitted the report is absent today. → who 代替了 the employee，也把兩句連起來
解剖
The employee (who submitted the report) is absent today. → 括弧裡是從句；括弧外是主句骨架

1判斷系統：看空格先問兩個問題

問題一

空格前面有沒有名詞，需要後面的句子來修飾它？

有 → 想關係子句
用關係代名詞或關係副詞

問題二

空格後面是不是完整句子，整塊內容當主詞 / 受詞 / 補語用？

是 → 想名詞子句
用 that / whether / who / what 等

快速記憶：空格後面子句「缺東西」（缺主詞 / 受詞 / 所有格）→ 關係代名詞。空格後面子句「完整」→ 名詞子句連接詞 或 關係副詞。

that 的三個使用限制：① 逗號後不用 that（非限定子句）　② 介系詞後不用 that　③ 所有格不用 that

3關係副詞速查（when / where / why）

先行詞關係副詞可改寫成例子
地點名詞wherein / at whichthe office where we work
時間名詞whenon / in whichthe day when we met
reasonwhyfor whichthe reason why he left
how 特別提醒： how 本身已帶「方式」意思，不和 the way 連用。
✅ This is how it works. / This is the way it works.
❌ This is the way how it works.

4名詞子句速查（that / whether / 疑問詞）

連接詞意思後面常見句型
that（無意思，純引導）完整句I know that S+V / The problem is that S+V
whether / if是否完整句I wonder whether S+V / Whether S+V is unknown
who / what / which疑問詞子句（陳述語序）determine who will ... / decide what to do
how / when / where疑問詞子句（陳述語序）explain how it works
The reason is that 陷阱： reason 已是「原因」，because 也是「因為」→ 語意重複，TOEIC 不選 because。
✅ The reason is that + S+V　　❌ The reason is because + S+V

5who vs whom：一個快速判斷法

who（主格）

空格後面沒有主詞（直接接動詞）

the employee who submitted
→ submitted 的主詞就是 who

whom（受格）

空格後面已有主詞（主詞 + 動詞）

the client whom we met
→ we 是主詞，met 是動詞，whom 是受詞

介系詞後面一定用 whom： to whom / for whom / with whom（不用 who）

🪤關係子句 & 名詞子句七大陷阱

看到人就選 who，忘了看後面有沒有主詞
正確做法：先行詞是人 → 要看後面子句缺的是主詞還是受詞
✅ The woman ______ we met is our client. → 後面有 we（主詞），缺的是受詞 → whom
❌ The woman WHO we met ✗ → 應該是 The woman WHOM we met ✓
逗號後用 that
正確做法：非限定關係子句（有逗號）不能用 that
✅ Ms. Holloway, WHO has worked here, has retired. ✓ → 有逗號，必須用 who/which/whom
❌ Ms. Holloway, THAT has worked... ✗
介系詞後直接用 that
正確做法：介系詞後面不能用 that，要用 which（事物）或 whom（人）
✅ The project for WHICH we prepared → 介系詞 for + which ✓
❌ The project for THAT we prepared ✗
the reason is because
正確做法：reason 已是「原因」，because 重複，TOEIC 答案選 that
✅ The reason is THAT the weather was bad. ✓
❌ The reason is BECAUSE... ✗ → reason + because 雙重「因為」
the way how
正確做法：how 本身已帶有「方式」概念，不和 the way 連用
✅ This is HOW it works. ✓ / This is the way it works. ✓
❌ This is the way HOW it works. ✗
what 前加先行詞
正確做法：what = the thing that（本身已包含先行詞），前面不能再加 the thing
✅ WHAT I need is time. ✓ / The thing THAT I need is time. ✓
❌ The thing WHAT I need... ✗
時間名詞誤選 where，地點名詞誤選 when
正確做法：先確認先行詞：地點 → where；時間 → when；原因（reason）→ why
✅ the day WHEN we met ✓ / the city WHERE I grew up ✓
❌ the day WHERE we met ✗ / the city WHEN I grew up ✗

📌本課重點句型 & 搭配

句型 / 搭配中文例句
make sure that + S+V確保……Please make sure that all forms are complete.
report / announce that + S+V報導；宣布……The newsletter reports that he will retire.
determine / decide who / what決定誰 / 什麼The manager has not decided which to adopt.
The reason is that + S+V原因是……（不是 because）The reason is that the weather was bad.
介系詞 + whom（人）給 / 為 / 與 誰The assistant, to whom you sent the forms, ...
介系詞 + which（事物）為了 / 靠 / 關於 哪個The building, for which a fund was set aside, ...
whose + 名詞其……的（所有格）The engineer whose computer you are using ...
whether to V是否要……The manager discussed whether to postpone.
be responsible for負責……She is responsible for the survey.
be transferred to被調到……He was transferred to the new branch.
